asio-server 문서

C++23 / standalone ASIO 기반 분산 게임 서버. 존 단위 스레드 어피니티로 락 없이 게임 상태를 처리하는 구조를 실무 서버 모양에 맞춰 재현한 포트폴리오.

전체 그림

Client ──▶ GatewayServer ──▶ WorldServer ──▶ ZoneServer ──▶ SQL Server
           (순수 릴레이)      (라우팅 + DB)    (게임 로직)
                                  ▲
                              GmTool (9300)
프로세스역할스레드
Gateway클라이언트 accept, 순수 릴레이I/O 2
World라우팅, DB 관문, 공통 콘텐츠I/O 2 · BASIC 8 · DB 4
Zone존/플레이어 권위 상태I/O 2 · LB 4 · Player 8 · ZoneSpace n · Broadcast 1

서버별 문서

Client C#/MonoGame 시각 클라이언트. 눈으로 확인하는 것과, 지금 클라이언트가 메워주고 있는 서버의 빈자리. GatewayServer 클라이언트가 아는 유일한 서버. 게임 로직 0, I/O 스레드 2개. WorldServer 누가 어느 존에 있는지 아는 유일한 서버. 존 이동은 여기 한 줄로 끝난다. ZoneServer 레인 네 개, 주인이 다르면 스레드가 다르다. UnitOfWork와 역순 롤백. DB 계층 스키마·SP 골격·트랜잭션. UnitOfWork 하나 = 트랜잭션 하나. 성능 측정 1만 세션까지의 처리량·지연 백분위와, 숫자보다 중요한 "어떻게 쟀는가".

패킷 시퀀스 다이어그램

C2ZMailAdd → DB 우편 하나가 Gateway·World·Zone 두 레인·DB 레인을 지나는 전 경로. C2ZMailBuy — 역순 롤백 모델 두 개에 걸친 트랜잭션이 실패했을 때 되돌아가는 장면. 존 핸드오프 재접속 없이 존을 넘는다. 스레드 간 이동과 프로세스 간 이동의 차이.
